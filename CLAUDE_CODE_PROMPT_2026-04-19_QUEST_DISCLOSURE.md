## Phase 1: Parser + generated content

### 1.1 Create `scripts/sync-quest-content.ts`

Parses `QUEST_MASTER_SHEET.md` starting from the first `### Quest ` heading. Rules per SPEC_05 Content sync workflow section. Summary:

- Quest block heading: `/^### Quest (\d+b?): (.+)$/`. Id is numeric unless the suffix is `b` (use a string key in that case).
- Metadata lines after the heading: `**Subtitle:**`, `**Rewards:**`, `**Time:**`, `**Video:**`, `**PDF:**`.
- Sections within a quest block: `#### Story Card`, `#### How To Do This Quest`, `#### Deliverable`, `#### Tips`, `#### Resources`, `#### Connected To`.
- `storyTeaser` is derived from `storyCard`: first paragraph plus (optionally) second paragraph, capped at 80 words combined across max 3 paragraphs.
- `howToSteps` parses `**Step N: heading.** body` into `{ heading, body }`.
- `connections` parses bullets in the Connected To section. Any bullet starting with "Comes before" extracts quest ids. Any other bullet becomes a `referencedBy` string.

### 1.2 Emit `client/src/data/questMasterContent.ts`

Top-of-file banner comment:

```ts
// GENERATED FILE. Edit QUEST_MASTER_SHEET.md instead, then run:
//   pnpm sync:quest-content
// Do not edit this file by hand.
```

Type shape per SPEC_05. Single exported const `QUEST_MASTER_CONTENT: Record<number | string, QuestMasterContent>`.

**Deterministic output.** Sort keys numerically (with `9b` slotted after `9`). Use 2-space indent, single quotes, trailing commas. Running the script twice on unchanged input produces byte-identical output.

### 1.3 Wire into `package.json`

Add:

```json
"sync:quest-content": "tsx scripts/sync-quest-content.ts"
```

### 1.4 Run it once

```bash
pnpm sync:quest-content
```

Result: `client/src/data/questMasterContent.ts` exists with entries for every quest currently in `QUEST_MASTER_SHEET.md` (Quests 0-13 plus 9b, at time of writing).

## Phase 6: State model, interaction polish, ship gate

### 6.1 Lift expansion state to the grid parent

Find the parent in `Quest.tsx` that maps over the seasonal quest arrays. Add:

```tsx
const [expandedQuestId, setExpandedQuestId] = useState<string | null>(null);
const [expandedCommitted, setExpandedCommitted] = useState(false);
```

Handlers `handleExpand`, `handleCollapse`, `handleNavigate` per SPEC_05.

Pass `isExpanded`, `onExpand`, `onCollapse`, `onNavigate` down to each `QuestCard`.

### 6.2 Hover preview vs click commit (desktop only)

- `onMouseEnter`: `handleExpand(id, false)`
- `onMouseLeave`: if not committed, `handleCollapse(id)`
- `onClick`: `handleExpand(id, true)` (promotes to committed). If already committed on this card, call `handleNavigate(id)`.
- On touch devices, `onClick` always runs (no hover). First tap commits tier 2. Second tap navigates.

### 6.3 Outside-click to collapse

Grid parent listens on `document` for `mousedown`:

```tsx
useEffect(() => {
  const handler = (e: MouseEvent) => {
    const target = e.target as Element;
    if (!target.closest('[data-quest-card="true"]')) {
      setExpandedQuestId(null);
      setExpandedCommitted(false);
    }
  };
  document.addEventListener('mousedown', handler);
  return () => document.removeEventListener('mousedown', handler);
}, []);
```

### 6.4 Escape to collapse

```tsx
useEffect(() => {
  const handler = (e: KeyboardEvent) => {
    if (e.key === 'Escape' && expandedQuestId) {
      setExpandedQuestId(null);
      setExpandedCommitted(false);
    }
  };
  document.addEventListener('keydown', handler);
  return () => document.removeEventListener('keydown', handler);
}, [expandedQuestId]);
```

### 6.5 Scroll into view on expand

Inside `QuestCard`, when `isExpanded` flips to true:

```tsx
useEffect(() => {
  if (!isExpanded) return;
  const rect = cardRef.current?.getBoundingClientRect();
  if (!rect) return;
  const overflow = rect.bottom - window.innerHeight;
  if (overflow > 0) {
    window.scrollBy({ top: overflow + 16, behavior: 'smooth' });
  }
}, [isExpanded]);
```
