# Investor Return Models Research

## Real Estate Fund Models

### Distribution Waterfall Structure
The standard real estate fund uses a tiered distribution model:

1. **Return of Capital**: Investors first receive their original investment back
2. **Preferred Return (Hurdle)**: Typically 6-8% annual return to LPs before GP participates
3. **GP Catch-up**: GP receives portion until reaching target split
4. **Profit Split**: Remaining profits split (commonly 80/20 LP/GP)

### REIT Dividend Model
- REITs must distribute at least 90% of taxable income as dividends
- Quarterly dividend payments (most common)
- Provides steady income stream to investors
- Tax-advantaged structure

### Real Estate Syndication Returns
- 5-year typical hold period
- 6-8% average annual cash-on-cash returns
- Capital appreciation at exit
- Total returns often 15-25% over investment period

## Venture Capital Models

### VC Distribution Tiers
1. **Return of Invested Capital**: First priority
2. **Preferred Return**: Usually 8% hurdle rate
3. **GP Catch-up**: Manager catches up to target carry
4. **Carried Interest**: Typically 20% of profits above hurdle

### Exit Strategies
- IPO (Initial Public Offering)
- Strategic acquisition (M&A)
- Secondary sale
- Buyback
- Target: 3-5x returns within 3-7 years
- Top performers aim for 10-20x returns

## Impact/Regenerative Finance Models

### Blended Value Approach
- Financial returns + social/environmental returns
- Some accept below-market financial returns for higher impact
- "Regenerative returns" concept: lower financial + dramatically higher social/environmental

### Impact Fund Structures
- Similar to traditional PE/VC but with impact metrics
- IRIS+ framework for measuring impact
- Dual objective: financial AND social/environmental returns

## Key Best Practices for ReGen Civics

1. **Transparent waterfall structure** with clear priority of distributions
2. **Preferred return** to protect investor capital (6-8% industry standard)
3. **Regular distributions** (quarterly or annual) for cash flow
4. **Multiple exit pathways**: land appreciation, project revenue, token liquidity
5. **Blended value reporting**: financial + regenerative impact metrics
6. **Stakeholder alignment**: unique model where alliance members share in success
