# Twinray Animation Reference Notes

## Animation Concept
- Scroll-triggered parallax animation
- Human figure with chakra points that reveal as user scrolls
- Starts with "Scroll to Activate" prompt
- Shows 7 chakra points along the body (crown to root)
- Chakra colors: violet (crown), indigo (third eye), blue (throat), green (heart), yellow (solar plexus), orange (sacral), red (root)
- Figure becomes more luminous/glowing as scroll progresses
- Ends with radiating energy circles and a call-to-action button

## Implementation Plan for ReGen Civics
- Create a scroll-triggered section with fixed background
- Use CSS transforms based on scroll position
- Human silhouette with chakra points
- Text reveals: "Regeneration happens within" then "You"
- Match site's green/earth color palette
- Use framer-motion for smooth animations
