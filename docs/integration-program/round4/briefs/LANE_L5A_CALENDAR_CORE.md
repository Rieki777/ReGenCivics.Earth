# Lane L5a: the village calendar core

Worktree `wt-r4-calendar`, branch `wt/r4-calendar`, migration `0085`. Code refs: game-amora `135db66`; line numbers are hints, anchor by content.

## Objective

Turn the events module into the village's one calendar: the `events` table generalised so every dated thing (gatherings, quest windows, sky, cycle marks, seat terms, imported calendars) lives in one table behind one read. Ship village time for every viewer, one true lunar clock that freezes the past, the two-ring year wheel with stacked Months|Moons views, a public `.ics` feed, Admin subscription to external calendars, and the CycleClock moon ring fix.

## Design

1. **One table (§10.5, N7).** `0085`: `events` gains `kind` enum (`gathering,quest-window,festival,season,sky,cycle-mark,seat-term,call,loan-due,notice-end,milestone,external,meet-me`, default `gathering`; append-only, enums are ordinal per `0059`), `source_module`, `source_id`, `layer` enum (`village,circle,household,private,admin,public`, default `village`), `all_day`, `recurrence` json, `external_source_id`, `external_uid`, `removed_at`; unique `(source_module, source_id)` and `(external_source_id, external_uid)`. `event_rsvps` gains `occurrence_key varchar(10) NOT NULL DEFAULT ''` (village-time `YYYY-MM-DD`, empty for one-offs); unique key becomes `(event_id, user_id, occurrence_key)` (§8 item 27). `quests` gains nullable `starts_at`, `ends_at`, `due_at`. New tables: `external_calendars` (name, layer, colour, url_host, secret_ref, last_polled_at, last_status, last_error), `calendar_month_names` (month_index 1..13, name, is_example), `calendar_feed_tokens` (user_id, token_hash, revoked_at).
2. **`calendar.ts`.** `calendarUpsert(pool, {kind, sourceModule, sourceId, title, startsAt, endsAt, allDay, layer, link, colour})` idempotent on `(source_module, source_id)`; `calendarRemove(sourceRef)` soft-removes; `listCalendarItems(pool, {from, to, viewer, layers, kinds})` is THE read (materialises recurrence, applies layer visibility over status and module gating, returns `occurrenceKey`); stable signature so L6 wraps it as a reader. `listGatherings` becomes a thin call over it.
3. **Providers (§9.3).** Quests: `questsRepo.add/update` call `calendarUpsert`/`calendarRemove` on their own save path when a date is set. Sky: `ensureSkyYear(year)` writes new/full moons, solstices, equinoxes, the year anchor, cross-quarters when enabled; idempotent by `sourceId` `sky:<kind>:<iso>`. Sources saved outside this zone (`gratitude_cycles` as `cycle-mark`, `SeasonConfig` seasons, `org_role_assignments.term_ends_at` as `seat-term`, `library_loans.due_on` and `member_exit.notice_ends_at` on `private`, `milestones` and `health_snapshots` on `admin`) are mirrored by an hourly reconciling `calendar-mirror` job, source named; the coordinator queues "call `calendarUpsert` on save" per owner. `festival` is a gathering the author marks (no festival table; hypothesis). Cycle close and season roll never fire from here (`scheduler.ts:18-22`).
4. **One true lunar clock.** `scripts/gen-lunar-table.mjs` (astronomy-engine, dev only; seed `round4/moons-2025-2028.mjs`) writes `shared/lunarTable.json`: new moon, full moon and season instants 2020-2050 as epoch minutes. `shared/lunar.ts` keeps its exports and constants; `cycleBoundsByNumber(n)` returns the mean boundary for `n < TRUE_CLOCK_FROM_CYCLE` and the table instant above it, the constant being the current cycle number at merge plus one, stated in the commit body; `moonPhase` becomes the fraction of the true lunation. Numbering unchanged (`round((t - REF)/SYNODIC)` maps each instant to one k; test uniqueness and consecutiveness). Header says hub follows in item 17. The pinned cycle 328 test (`shared/lunar.test.ts:32-35`) passes untouched.
5. **Year anchor and hemisphere.** Variables `calendar.year_anchor` (choice: december_solstice default, march_equinox, june_solstice, september_equinox), `calendar.hemisphere` (north), `calendar.cross_quarters` (false). Month 1 = first new moon after the anchor; 12 or 13 moons as the sky gives; the 13th "Blue Moon" (Q16). Names: number + village name from `calendar_month_names`, seeded with hemisphere-aware almanac names flagged `is_example`, shown with an example pill (retirement machinery not extended).
6. **Village time.** Windows "today / this week / this moon" in `SeasonConfig.timezone` (`gameConfig.ts:176`); `/api/events` adds `timezone` and `lunar` (month index, name, day, length); the client renders with `Intl.DateTimeFormat({timeZone})`, prints the zone name, shows viewer local time as a second line only when it differs. `daysUntil` stays UTC (the map depends on it); add `daysUntilInZone` beside it.
7. **UI.** `client/src/components/calendar/`: `YearWheel` grown from `CycleClock` (outer ring twelve months, inner ring true lunations as arcs of real length, four solar spokes, today hand; tap an arc opens that month), `WeekView` and `MonthView` with two stacked equal-height headers ("August 2026" over "Moon 8, Ricing Moon, day 12 of 30"), phase glyph per cell, lunar day under the Gregorian, a remembered `Months|Moons` switch. `Events.tsx` keeps `/events`, RSVP and the flat list as a "List" tab.
8. **`.ics` (§5 item 10).** `GET /api/events/calendar.ics` registered ABOVE `/api/events/:id` (the `by-structure` pattern, :8028); public layer, scheduled/cancelled/postponed, each VEVENT names the lunar month; hand-written RFC 5545 in `icsFeed.ts` (CRLF, folding, escaping, `UID`, `SEQUENCE`; `RRULE` for weekly/monthly, expanded instances for lunar/solar). Signed-in feed `?token=`: 32 random bytes, sha256 in `calendar_feed_tokens`, minted and revoked on the Events page, rate limited via `overLimit` (:3440), never logged.
9. **External calendars (§9.3, R28).** `POST/GET/DELETE /api/admin/events/calendars`: name, https url, layer, colour. URL stored via `putSecret("external_calendar_url:<id>")`; the row keeps host and last4; responses are projected, never the URL. `calendar-external-poll` job (3 h) fetches through `guardedFetchText` (SSRF guard, 1 MB cap), expands upstream RRULE 365 days out, imports by `UID` (insert, update, soft-remove when gone), `kind=external`, read-only mirror, RSVP still works. Audit rows through `recordEvent`. Security review before merge.
10. **CycleClock fix.** Pass moon age in days (`phase * SYNODIC_MONTH_DAYS`) or let `wheelState` take a fraction; the ring must visibly fill.
