## Design

1. **Vocabulary, `shared/power.ts`** (check-voice and the ratchet see every gloss). `SHAPES`: circle, pyramid, council, flat, steward, network, other, each `{id, label, gloss, spectrum 0..1}` from "one holds it" to "all hold it". `DECIDES_BY`: consent, consensus, majority, lead_decides, elders_decide, founder_decides, do_ocracy, delegated, hypha, other. `DOMAINS`: money, people, space_land, rules. `HOW_CHOSEN`: appointed_by_lead, elected_by_circle, rotates, volunteers, founder_appoints, other. Pure `shapeProblem`, `decidesByProblem`, `howChosenProblem`; `other` requires a gloss (1-160 chars); ids are closed.
2. **Data (`0083`).** `circles`: `decides_by varchar(32)`, `decides_by_gloss varchar(160)`, `decides_by_domains json` (`{money?, people?, space_land?, rules?}` each `{method, gloss?}`), all NULL. `org_roles`: `represents_circle tinyint(1) NOT NULL DEFAULT 0`, `how_chosen varchar(32)`, `how_chosen_gloss varchar(160)` (into `ROLE_COLS`, `rowToRole`, `WRITABLE`, `describeOrgChange`; never the export). `org_drafts.vision json`. `INSERT IGNORE` relation type `escalation` ("escalates objections to" / "hears objections from", symmetric 0, cover 0, sort 6) and append to `STARTER_TYPES`; deleted once, gone for good. `fx_rates` (`quote char(3)`, `rate decimal(18,8)`, `as_of date`, `source varchar(16)`, `fetched_at`; PK `(quote, as_of)`; base EUR). Village level: `module_settings.config` for `map` gains `power: {shape, shapeGloss?, decidesBy, decidesByGloss?}` via `setModuleConfig("map", …)` after `orgChart.ts` validation. `schema.ts` mirrors the `circles` columns.
3. **Rights (P10, N5).** `mayDeclare(viewer, circleId | "village")` in `orgChart.ts`, pure over `(isAdmin, hasCapability("org.declare"), live assignments, roles)`: admin, or `org.declare`, or a live non-example holder of a `represents_circle` role in that circle (village level: the first two only). Granting `represents_circle` and `how_chosen` is admin only through the existing `PUT /api/admin/org/roles/:id`. The ADR names the bridge as one narrow per-circle exception to "the seat plane never touches the gate" (`orgChart.ts:4-9`, `0049`), never a global capability, with the pinning test.
4. **Routes.** `GET /api/map` gains `power` (village shape, default method, glossary); circles carry `decidesBy`, `decidesByGloss`, `decidesByDomains`; roles gain `representsCircle`, `howChosen`, `termEnds` (earliest live term, structure tier); holders gain `avatar` (batched `users.primary_character_id` join `player_characters`, `avatarFor`) and `termEndsAt` behind `viewPeople`; plus `relations`, `relationTypes` (nodes only), `season: {current, nextRollAt}`, `viewer.mayDeclare: string[]`. Org block: `PUT /api/org/circles/:id/decides` (mayDeclare, validated, example rows refused, written like the admin circle PUT), `PUT /api/org/village/power` (admin or `org.declare`), `GET /api/org/vision`, `PUT /api/admin/org/drafts/:id/vision`; `recordEvent` on every write. `GET /api/fx/rates` returns `{base, asOf, rates}`, `max-age=3600`.
5. **Layouts, pure.** `layoutForShape(shape, inputs, villageRoles): NestedLayout` in `mapLayout.ts`: `circle` = today's ring pack untouched; `pyramid` = top-down tree, head seat on top; `council` = council seats on an inner ring; `flat` = one ring of equals; `steward` = the steward at centre inside one enclosing line; `network` = nodes on a wide ring with relation chords; `other` = circle plus its gloss in the legend. One output type, one renderer, framer-motion animates seats between shapes. Snapshot per shape on one fixture (`toMatchInlineSnapshot`, integers).
6. **Camera, pure.** `components/power/camera.ts`: `cameraAfter(state, event)` for tap circle / crumb / background / seat / Esc / search pick; view `[cx, cy, w]` through `interpolateZoom` (add `d3-interpolate` only; port the function if audit or bundle objects), 400 ms, 0 under reduced motion, `?focus=` pushed to history. A seat event returns an equal view (test).
7. **UI (spec 1-14, one component per point under `components/power/`).** `PowerMap.tsx`: SVG `role="group"`, every circle and seat `<g role="button" tabindex="0">` with an aria-label carrying state, arrows between siblings, Enter zooms/opens, Esc zooms out, live region "Now inside Land Care, 3 seats, 1 open"; siblings at 30%, labels for children of the focus only. `SeatGlyph`: open dashed hollow "+", partial pie with a notch per empty seat, filled avatars up to 3 then "+n", forming dotted hourglass, expired greyed clock; colour never alone. `HolderCard`: role, circle, holder, focus, term end, how the next holder is chosen, one action, Hypha DHO chip through `useModules().hypha` when the method is `hypha`. `SearchBar`: type-ahead over seats, circles, aims, accountabilities, holders, deterministic, zero tokens; a pick zooms and pulses; Ask still calls `/api/assistant/coordinate`. `FilterChips` (open, mine, expiring, one circle; an avatar tap filters to that person). `RelationLines`: off by default; double links as two short arcs, `org_relations` as dashed chords for the focused circle only, escalation a thin arrow. `TermMarkers`: amber arc within 30 days, clock on expired, season ring with the next roll. `Legend`: five glyphs with counts, the shape spectrum with the village marker, decides-by chip with gloss on tap, currency picker in the footer. `DecideLens`: circles coloured by method, domain chips, overrides as marks. `ShapePicker` for mayDeclare viewers. Accordion below 480 px, when the smallest seat would draw under 24 px, or by choice; above 400 seats avatars only inside the focus; print stylesheet and SVG/PNG export from the same viewer-tiered payload.
8. **Setup walk (§8 item 16).** `SetupWalk.tsx`: open and partial seats in order, then circles without a method, then the village shape; assign / skip / open call; member tray with avatars; assign posts to the existing `POST /api/admin/org/roles/:id/holders`; card stack on mobile; ends at "publish structure to the network?".
9. **Power Now | Vision (P1, N2).** Vision = open `org_drafts` drawn as ghosts plus `vision = {objectives: [{text, metric, target, current, source: measured | declared, done}], trigger: {all_objectives_done, by?}}`. `visionProgress(vision, measures)` in `orgDrafts.ts` is pure; measured v1: `seats_filled`, `seats_filled_in:<circleId>`, `members_at_stage:<stageId>`, `seasons_completed`; declared ones a human ticks. When all are done the panel says "Vision conditions met: apply this structure?" and links to the existing publish button. Nothing calls `publishDraft` except that button (test).
10. **Currency (P8, N4).** `project.country`, `project.fiatCurrency` (Amora `CR`, `CRC`; blank country resolves to `CHF`); `users.prefs.displayCurrency`; `shared/money.ts` `formatMoney({amountMinor, currency}, display?)` using `Intl` for the exponent (the `priceLine` pattern, `modules.ts:774`) and `convertMinor(rate)`; the original currency shows whenever no rate exists. `fxRates.ts` daily job through `guardedFetchJson` (`toolcheck.ts:101`) against the ECB data portal JSON (`EXR/D.<codes>.EUR.SP00.A?lastNObservations=1&format=jsondata`). Hypothesis to verify at dispatch: the ECB list carries no CRC, so Amora shows CRC unconverted until an admin adds a `manual` row; the picker says so.
11. **Publish surface.** `buildOrgExport` gains top-level `shape` and per-circle `decidesBy` + `decidesByDomains` ids; glosses stay off (free text can hold a name); circle markdown adds "Decides by: consent". Grep every reader of every field touched (`buildOrgExport`, `circleMarkdown`, `orgIndexMarkdown`, `villageReaders.ts`) first.
