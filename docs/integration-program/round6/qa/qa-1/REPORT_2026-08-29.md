## 6 · Method notes, so the numbers can be trusted or discarded

- Playwright is not a dependency of this repo. It was junctioned in from a sibling worktree's
  node_modules; **no package.json and no lockfile was touched.**
- My own scroll-behaviour init script threw before document.head existed on the first sweep and put
  one pageerror on **every page**. It was fixed and every sweep re-run. Any error count from the first
  pass is mine, not the product's.
- Every numeric band asserts finite before comparing. NaN, undefined and unparsed values are counted
  and printed as NOT MEASURABLE and never treated as passing.
- Negatives were proved against a positive in the same run: the reachability comparison asserts a
  non-zero examined count before believing "zero unreachable" (6,248 is greater than 0), and the tally
  comparison prints "NO CHECK RAN" rather than a pass if no comparison executes.
- git grep was not used for any negative claim in this report.
- The .test-lock was free at dispatch and I did not run the full suite, so I did not take it.
- Probe scripts are committed inside the worktree at scripts/qa/r6-member/ on commit 3e9774b, staged
  by explicit path. Nothing pushed.
